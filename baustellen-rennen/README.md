# Baustellen-Rennen

Kartrennen mit Mini-Baumaschinen für den Browser. Es gibt keine Zufalls-Items: Wer hinten liegt, darf die Strecke umbauen. Bezahlt wird mit Baupunkten (BP), die man nur durch Aufholen und Überholen verdient.

**Starten:** `index.html` doppelklicken. Für den ersten Start braucht es Internet, weil die 3D-Bibliothek three.js von einem CDN geladen wird.

Die ausführliche Anleitung folgt mit dem fertigen Stand.
